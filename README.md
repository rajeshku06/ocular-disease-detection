# OcularAI

AI-Based Computer Aided Diagnosis System for Multiple Ocular Disorders using Deep Learning.

---

## Overview

OcularAI is a Deep Learning based web application developed for automatic detection of ocular diseases such as:

- Cataract
- Glaucoma
- Diabetic Retinopathy
- Normal Eye Condition

The system uses retinal fundus images and a DenseNet121 CNN model for prediction.

---

## Features

- AI Disease Detection
- ESP32-CAM Integration
- Real-Time Prediction
- Image Processing Pipeline
- SQLite Database
- Modern Web Dashboard

---

## Technologies Used

- Python
- Flask
- TensorFlow/Keras
